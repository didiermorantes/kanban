# 🧩 Sistema Web Kanban – Gestión de Proyectos

Sistema web tipo Kanban para la gestión colaborativa de proyectos y tareas,
desarrollado en PHP bajo arquitectura MVC, con control de roles y métricas avanzadas.

---

## 🚀 Características
- Gestión de usuarios y roles
- Proyectos con responsables
- Miembros por proyecto
- Tablero Kanban con Drag & Drop
- Métricas profesionales (CFD, WIP)
- Filtros y ordenamientos
- Interfaz clara y responsiva

---

## 🧱 Arquitectura
- PHP (POO)
- MVC + Front Controller
- MySQL
- HTML, CSS, JavaScript nativo
