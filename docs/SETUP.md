# Instalación y Configuración

---

## Requisitos
- PHP 8.x
- MySQL / MariaDB
- Servidor web (Apache recomendado)
- XAMPP / Laragon / similar

---

## Instalación

1. Clonar o descargar el proyecto
2. Configurar base de datos en `config/db.php`
3. Importar el archivo SQL ubicado en:
docs/database.sql

markdown
Copiar código
4. Verificar permisos de Apache
5. Acceder a:
http://localhost/kanban/public
